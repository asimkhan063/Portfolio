# Mohammad Asim — Portfolio

A responsive, single-page portfolio website built with HTML, CSS, and vanilla JavaScript. Open `index.html` in a browser to preview it, or publish the folder with GitHub Pages, Netlify, or Vercel.

## Personalize before publishing

- Confirm that the LinkedIn and GitHub profile URLs are correct.
- Replace each “View GitHub profile” project link with the matching repository URL when available.
- Update project descriptions or add screenshots as you like.

## Files

- `index.html` — page content and metadata
- `styles.css` — responsive layout and visual styles
- `script.js` — mobile navigation behavior
